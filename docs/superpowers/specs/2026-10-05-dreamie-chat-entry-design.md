# Dreamie 对话入口页设计

## 目标

为 Dreamie 小羊打造一个可在浏览器打开的手机竖屏 Agent 对话入口页。首版聚焦建立陪伴感与提供清晰的对话入口，而非完整的聊天记录、账户体系或服务端 Agent 能力。

成功标准：用户在首屏能看见小羊、理解可以和它聊天、输入并发送一条消息，随后获得明确的界面反馈。

## 视觉方向

- 画布：优先适配 375–430px 宽的手机竖屏；桌面浏览器中将手机画面居中展示。
- 色彩：深靛蓝到薰衣草紫的纵向渐变，配合低饱和星点与柔和光晕，参考提供的蓝紫色调。
- 主视觉：`assets/mascots/dreamie-lamb-lavender-pillow-awake-v11.png` 中的小羊坐在深色绒面沙发上。沙发用深海军蓝/蓝黑色表现，扶手、靠垫和轮廓用淡紫月光高光区分层次。
- 品牌感：顶部保留简洁的 Dreamie 名称、在线状态和圆形设置入口；避免在主视觉周围堆叠功能卡片。
- 可读性：正文与交互控件使用高对比浅色文字；渐变、背景纹理和发光均不影响输入区域的可读性。

## 布局与组件

页面由四个区域组成：

1. 顶部栏：品牌名、"陪你慢慢聊"在线状态和设置按钮。
2. 场景区：小羊与深色沙发为中心，背景加入星点、月光和地面阴影；场景随屏幕高度弹性缩放。
3. 引导区：欢迎文案与三个快捷开场话题。点击话题会将文案写入输入框，便于修改后发送。
4. 固定聊天浮层：底部半透明圆角面板，包含可换行的文本输入框、语音/附件装饰按钮和发送按钮；安全区留白保证手机底部操作舒适。

当用户发送消息时，页面将显示用户消息气泡并更新小羊的回应文案（本地模拟）。首版不调用真实 Agent API、不保存跨刷新消息、不提供语音录制或附件上传功能；相关图标仅用于完成入口视觉。

## 交互与状态

- 初始状态：显示欢迎语、快捷话题与空输入框，发送按钮在无内容时为不可用状态。
- 输入状态：有非空文本时激活发送按钮，输入框支持 Enter 发送及 Shift+Enter 换行。
- 已发送状态：将文本追加到本地消息区，清空输入框，更新引导文案为确认/倾听状态。
- 快捷话题：将选中的话题填入而不自动发送，确保用户掌控最终内容。
- 可访问性：所有图标按钮均有文字标签；输入框有明确标签；焦点环、键盘操作与减少动画偏好均受到支持。

## 技术与验证

- 采用一个轻量前端页面（HTML、CSS、原生 JavaScript），不引入构建依赖；本地静态服务器即可在浏览器展示。
- 页面布局以 CSS 自定义属性、Grid/Flex 和媒体查询实现；小羊素材直接使用项目内资源。
- 使用浏览器自动化或 DOM 测试验证：初始输入状态、快捷话题填充、发送消息、键盘发送与窄屏布局。
- 视觉验收重点：375px 宽度无横向滚动、核心输入控件始终可见、文字与蓝紫背景有足够对比度。

## 非目标

- 真实 Agent 后端、流式回复和账户登录。
- 历史会话持久化。
- 真实语音输入、文件上传或设置面板。
- 多页面导航。
